# Fabian

Daily scam practice for the people you love.

A Duolingo-style habit app. An older parent practices spotting scam texts, emails and call scripts in 5-minute drills. The adult child pays and sees her streak and progress, not her messages. Named for Fabius Maximus, the general who won by refusing to be rushed.

Status: pre-MVP. See [docs/MVP.md](docs/MVP.md).

## Stack (planned)

- Next.js (React, TypeScript), mobile-first web app
- Supabase: database and magic-link login
- Vercel: hosting, with a preview URL on every branch
- Drills live in `content/drills.json`, not the database

## Rules for working in this repo

- Plain words. No dashes used as drama. No exclamation points in product copy.
- Never write "elderly," "senior citizen," "vulnerable" or "gullible" in product copy.
- Drills use generic names ("your bank"), never real brand names.
- Do not claim the app prevents fraud. Say "practice," not "protect."
- Do not collect anything beyond email and drill answers.
